# Security

## Supported versions

`main`, until the first tagged release.

## Reporting a vulnerability

Report privately by email  rather than opening a public
issue, with what you found and, if you can, a way to reproduce it.

## Scope

A crafted file that crashes or hangs a reader (`h264`, `mp4`, `flv`, `ts`)
is in scope: these parse recordings from an untrusted source.
