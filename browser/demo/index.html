seimark publish and watch

The left panel publishes a generated canvas over WHIP and stamps every access unit with a seimark marker. The right panel subscribes to the same stream over WHEP and reads those markers back off the received track. Every marker in both directions is also logged to the console, prefixed publish or watch. No camera and no dependencies.

Read the recording

The server records what it receives under e2e/recordings/, one file per session named after the stream — seimark for the prefilled URLs. e2e/mediamtx.yml records in fMP4, so the files are .mp4. List the directory, then dump one with the Go CLI from the repository root: 

go build -o seimark ./cmd/seimark
ls browser/e2e/recordings/
./seimark dump browser/e2e/recordings/seimark_<timestamp>.mp4
